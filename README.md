# Proyecto Final – React + Django

## Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate          
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser   
python manage.py runserver         
```

## Frontend
```bash
cd frontend
npm install
npm run dev                      
```
